The four main commands to know though are: [^1]

1. DIR - This command shows whats in the directory
2. CD .. - This command goes back one directory
3. RMDIR - This command removes a folder
4. MKDIR - This command creates a folder


|	Command		|	Example		|
|-----------------------|-----------------------|
|	DIR		|C:\users\test\dir	|
|	CD ..		|c:\users\cd ..		|
|	RMDIR		|RMDIR Folder1		|
|	MKDIR		|MKDIR Folder2		|
|			|			|
|-----------------------|-----------------------|


Just a quick note on these commands, particularly RMDIR, you can <mark>add /S and /Q</mark> to <mark>Delete subfolders quietly</mark>
